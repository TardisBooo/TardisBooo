# Public profile policy

The profile uses only the public alias `Tardis`.

The public project list is limited to Möbius, tigang-reminder, ViewAtom,
AgentTect, C++ Memory Pool Benchmark and SkillAnything. Descriptions should
focus on the public product or source repository and must not disclose a real
name, personal contact details, location, education or employment history.

New commits use the GitHub noreply identity. Before publishing, scan visible
Markdown, repository metadata and assets for accidental personal information.
