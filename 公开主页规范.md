# Public profile policy

The profile uses only the public alias `Tardis`.

The public project list is limited to Möbius, mobius-connect, harness-daily,
prewalk, tigang-reminder, ViewAtom, AgentTect and C++ Memory Pool Benchmark.
SkillAnything is not listed. Descriptions should focus on the public product
or source repository and must not disclose a real name, personal contact
details, location, education or employment history.

The personal portfolio is a separate section (and the GitHub profile website
URL). It is not listed under Public links. Public links are the Möbius product
page and ViewAtom. Do not include tigang-reminder in Public links.

Do not feature the profile repository or the portfolio repository as project
cards. GitHub's pin controls are separate from this README.

New commits use the GitHub noreply identity. Before publishing, scan visible
Markdown, repository metadata and assets for accidental personal information.
