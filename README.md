# Tardis

Agent products and systems engineering projects for making technical work
easier to inspect, continue and share.

## Focus

Agent and systems engineering.


## Projects

- [Möbius](https://github.com/TardisBooo/Mobius) — TardisBooo/Mobius, a Rust/Tauri Windows workspace for Codex, Claude Code, Pi, Grok and OMP. Precise `@session` references, local FTS/BM25 search, reference-only handoffs, a project graph, Markdown notes, a multimedia canvas and native PowerShell tabs. Current preview: [v0.3.19](https://github.com/TardisBooo/Mobius/releases/tag/v0.3.19). [Product page](http://8.137.87.76/mobius/). Not Microsoft Mobius or ControlTheory Möbius.
- [mobius-connect](https://github.com/TardisBooo/mobius-connect) — CLI and stdio MCP for Möbius. Search, cite, graph and hand off local coding-agent sessions. References only; MCP cannot mint approvals.
- [harness-daily](https://github.com/TardisBooo/harness-daily) — a local CLI and marketplace plugin that turns yesterday's Codex, Claude Code, Grok Build, Pi and OMP sessions into an enterprise-style daily report, written by the host agent CLI.
- [prewalk](https://github.com/TardisBooo/prewalk) — a two-phase execution layer for Codex CLI and Claude Code: the frontier planner completes and verifies the first edit, then a cheaper executor inherits the trajectory or a durable checkpoint. It adds atomic state transitions, fail-closed routing, reject-retry validation and recoverable handoffs.
